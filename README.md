# 🌊 Salve os Oceanos

Projeto desenvolvido no início da faculdade como parte de uma atividade acadêmica, utilizando **HTML, CSS e JavaScript**.

A proposta do projeto foi desenvolver uma página web com foco na conscientização sobre a preservação dos oceanos, colocando em prática conceitos básicos de desenvolvimento web e estruturação de páginas.

## 📚 Sobre o projeto

Este foi um dos meus primeiros projetos desenvolvidos durante a faculdade de **Ciência da Computação**.

O projeto teve como objetivo colocar em prática conhecimentos iniciais de desenvolvimento front-end, incluindo:

- Estruturação de páginas com HTML;
- Estilização e organização visual com CSS;
- Interações básicas utilizando JavaScript;
- Organização de arquivos de um projeto web;
- Desenvolvimento de uma interface voltada para conscientização ambiental.

## 🎯 Objetivo

Criar uma página informativa e visualmente agradável sobre a importância da preservação dos oceanos e dos impactos causados pela poluição marinha.
